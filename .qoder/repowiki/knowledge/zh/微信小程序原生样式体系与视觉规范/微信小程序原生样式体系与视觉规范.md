该仓库采用微信小程序原生样式方案，未引入任何第三方 UI 框架（如 Vant Weapp、TDesign 等）或 CSS 预处理器（Sass/Less），全部使用原生 wxss + rpx 单位进行样式编写。

**样式架构与组织方式**
- 全局样式集中在 `miniprogram/app.wxss`，定义页面基础样式（背景色 #f6f6f6、字体族 -apple-system/BlinkMacSystemFont/Segoe UI Roboto、主文本色 #333、基础字号 28rpx）、通用组件类（.container、.card、.divider、.loading-mask）以及按钮与状态标签的公共样式。
- 每个页面独立维护自己的 `.wxss` 文件（index、sync、history、bind），遵循「页面级样式隔离」原则，无跨页面共享的复杂样式模块。
- 图片资源统一放置在 `miniprogram/images/` 目录下，图标按功能分类存放于 `images/icons/`。

**设计系统与视觉规范**
- 色彩体系：主色调为 #0052B9（蓝色系），辅助色包括成功绿 #52c41a、警告橙 #fa8c16、错误红 #ff4d4f；各平台品牌色通过渐变区分（Garmin CN: #00a3d9→#0088b8、Garmin Global: #0052B9→#003d8a、COROS: #ff6b00→#e05e00）。
- 间距系统：统一使用 rpx 单位，常见间距值为 20rpx、24rpx、30rpx、40rpx，圆角统一为 12rpx/16rpx/24rpx。
- 组件化样式：定义了 .btn-primary/.btn-secondary/.btn-danger 三级按钮语义，.tag-success/.tag-warning/.tag-error/.tag-info 四种状态标签，.empty-state 空状态模板，以及 .loading-mask 加载遮罩。
- 响应式策略：完全依赖 rpx 相对单位适配不同屏幕尺寸，未使用媒体查询。

**交互与动效约定**
- 按钮点击反馈统一使用 opacity: 0.85 的 :active 伪类效果。
- 加载动画通过 @keyframes spin 实现旋转指示器，用于同步中遮罩和加载更多场景。
- 弹窗/模态框采用固定定位 + 半透明遮罩层（rgba(0,0,0,0.5)）+ 居中绝对定位内容区的标准模式。

**约束与限制**
- 未使用 CSS 变量或主题切换机制，颜色值直接硬编码在样式文件中。
- 无样式lint配置或自动化检查工具，样式一致性依赖开发者自觉。
- 小程序原生限制下，避免使用高级CSS特性，所有样式均兼容微信渲染引擎。
