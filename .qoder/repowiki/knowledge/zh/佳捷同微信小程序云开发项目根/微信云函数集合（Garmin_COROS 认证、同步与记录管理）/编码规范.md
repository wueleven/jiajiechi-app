- 所有云函数统一以 exports.main 作为入口，通过 event.action 分派到内部处理函数，未知 action 返回 { success: false, message: '未知操作' }
- 通过 cloud.getWXContext().OPENID 获取当前用户标识，并以此作为所有数据库查询的过滤条件
- 错误处理采用 try/catch 包裹，统一返回 { success: false, message: err.message || '服务器错误' } 格式
- 数据库操作统一使用 db.collection('xxx').where({ openid }).get() 模式，避免跨用户数据泄露
- 敏感凭据（密码、OAuth token）入库前使用 AES-256-GCM 加密，解密时兼容旧明文格式
