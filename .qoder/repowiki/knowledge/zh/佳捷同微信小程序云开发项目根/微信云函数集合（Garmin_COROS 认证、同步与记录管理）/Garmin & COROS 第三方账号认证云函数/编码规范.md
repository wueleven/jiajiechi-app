- 所有对外 HTTP 请求统一使用 axios 并设置 `validateStatus: (s) => s >= 200 && s < 500` 以自定义状态码处理，禁止使用默认重定向策略。
- 错误处理采用 try/catch 捕获后返回 `{ success: false, message: err.message || '...' }` 的统一格式，成功路径返回 `{ success: true, ... }`。
- 敏感数据（密码、MFA 中间态）写入数据库前通过 `encryptPassword` 进行 AES-256-GCM 加密，读取时按需解密，密文格式为 `iv:tag:ciphertext` 三段 hex 拼接。
- Cookie 会话通过 axios 响应拦截器手动收集 set-cookie 并存入 `session._collectedCookies`，后续请求通过 `Cookie` 头复用，不依赖第三方 cookie jar。
- 多平台扩展通过统一的 `platform` 参数（garminCn / garminCom / coros）区分，数据库字段命名遵循 `${platform}` 和 `${platform}_mfaState` 的约定。
- 正则表达式集中定义在文件顶部常量（CSRF_RE / TICKET_RE / LOCKED_RE / MFA_RE / MFA_EXEC_RE），用于解析 Garmin SSO 页面内容。
