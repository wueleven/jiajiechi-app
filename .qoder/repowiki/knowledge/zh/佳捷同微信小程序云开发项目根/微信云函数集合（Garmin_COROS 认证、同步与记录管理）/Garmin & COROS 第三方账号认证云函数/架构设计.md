单文件云函数入口 `index.js`，通过 `exports.main` 接收 `action` 参数分派到各处理函数（getBindInfo / bindWithPassword / submitMfa / autoRelogin / corosBind / corosRefresh / unbind），形成 action-based 路由结构。
- 认证流程分层：`loginStep1`（提交账号密码→ticket 或 MFA）、`loginStep2Mfa`（提交验证码→ticket）、`getOauth1Token`（ticket→OAuth1.0a）、`exchangeOauth2`（OAuth1→OAuth2 Bearer）、`getUserProfile`（拉取用户信息），构成完整的 Garmin SSO + OAuth 链。
- 会话管理：使用 axios 拦截器手动收集 set-cookie 并维护 Cookie 头，替代内置 cookie jar。
- 数据存储：基于 wx-server-sdk 的 cloud.database() 操作 `users` 集合，按 openid 维度存储 garminCn / garminCom / coros 三个平台字段，MFA 中间状态以 `${platform}_mfaState` 字段暂存（5 分钟过期）。
- 安全层：密码使用 AES-256-GCM 加密后落库，解密在内存中完成；OAuth consumer key/secret 从远端 JSON 动态获取。
- COROS 子模块独立于 Garmin 流程，通过 `corosLogin` / `corosBind` / `corosRefresh` 调用 teamcnapi 接口，支持 regionId 路由到不同区域 API。
- 依赖方向单向：index.js → axios/oauth-1.0a/crypto/qs → 外部 Garmin/COROS HTTP API 和微信云数据库，无内部模块拆分。
