单文件云函数（index.js）+ 配置（config.json、package.json），通过 `exports.main` 统一入口按 `action` 分派到 `syncActivities` / `getActivities` / `getActivityDetail` 三个业务函数。
- 认证层：`getPlatformApi` 从 users 表读取用户绑定的 Garmin/COROS 凭证，自动检测并刷新 OAuth2 token，失败时调用 `garminAuth` 云函数执行 `autoRelogin`；COROS 使用独立的 `getCorosSession` 管理 session 与 regionId 路由。
- API 客户端层：基于 axios 创建带 Bearer 认证的实例，提供 `validateToken` / `shouldRefreshToken` / `refreshTokenAndRetryValidation` 实现统一的 401/5xx 重试与自动刷新。
- 数据源适配层：Garmin 侧封装 `fetchActivities` / `downloadGarminActivity` / `uploadGarminActivity`；COROS 侧封装 `fetchCorosActivities` / `downloadCorosFit` / `uploadToCoros`，将两者输出格式对齐为统一的活动结构。
- 同步编排层：`syncActivities` 根据 direction 参数决定六种方向（garminCn↔garminCom、garmin→coros、coros→garmin），以增量时间戳或 forceResync 控制去重，逐条写入 syncRecords 记录状态。
- 存储依赖：微信云数据库 users、syncRecords 集合；COROS 上传通过 AWS SDK v3 的 S3Client 直传至多区域 bucket（AWS/Aliyun OSS）。
