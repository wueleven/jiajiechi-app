- 所有对外 API 调用统一通过 axios 发起，并使用 validateStatus 拦截非 2xx 响应后自行解析 data/result/code 字段，而非依赖默认错误抛出。
- OAuth 令牌过期检测采用提前 300 秒刷新策略，刷新失败时回退调用 garminAuth 云函数的 autoRelogin，并在需要 MFA 时返回 mfaRequired 标记由前端处理。
- 每个同步活动先插入 syncRecords 记录（status=syncing），成功则更新为 success，失败则更新为 failed 并记录 errorMsg，保证可追溯。
- COROS 区域差异通过 COROS_REGION_CONFIG 映射表集中管理（regionId → teamapi/bucket/service/s3Endpoint），STS 签名也按 regionId 区分。
- 错误处理统一在 try/catch 中捕获，返回 { success: false, message } 结构，关键路径在 catch 内再次尝试 token 刷新后重试一次。
