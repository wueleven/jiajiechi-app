模块采用「入口脚本 + 领域 utils」的扁平分层结构：`src/` 下每个 `.ts` 文件对应一个独立可执行的 CLI 命令（如 `sync_garmin_cn_to_global.ts`、`migrate_garmin_cn_to_global.ts`、`rq.ts`），它们仅负责参数读取、调用具体业务函数并通过 `@actions/core` 与 Bark 通知上报结果；实际业务逻辑集中在 `src/utils/` 中按服务域划分——`garmin_cn.ts` / `garmin_global.ts` / `garmin_common.ts` 封装中国区/国际区 Garmin Connect API 客户端与活动下载上传流程，`google_sheets.ts` 通过 `google-auth-library` JWT 认证操作 Google Sheets，`sqlite.ts` 持久化 OAuth Session，`runningquotient.ts` 处理 RQ 站点登录与数据抓取，`strava.ts` 对接 Strava API，`number_tricks.ts` / `type.ts` 提供通用辅助。配置集中管理于 `src/constant.ts`，所有敏感凭据优先从 `process.env` 读取，回退到 `_DEFAULT` 常量。构建产物由 `Dockerfile`（基于 `node:lts-alpine3.19`）和 `docker-compose.yml` 编排，GitHub Actions 工作流位于 `.github/workflows/`，通过 `yarn sync_cn` / `sync_global` / `migrate_*` 等 npm script 触发执行。
