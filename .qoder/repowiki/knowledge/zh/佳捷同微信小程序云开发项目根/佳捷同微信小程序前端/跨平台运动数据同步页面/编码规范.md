- 页面状态统一集中在 Page.data 中声明（如 bindStatus、syncPairs、pairDirections、syncProgress），并通过 this.setData 更新，避免直接操作 DOM。
- 平台配对以固定常量 SYNC_PAIRS 数组定义，包含 id、left、right 三元组，运行时根据 bindStatus 过滤生成可用列表。
- 云函数调用统一使用 wx.cloud.callFunction 并传入 { name, data: { action, ... } } 结构，action 作为区分不同操作的标识符。
- 异步错误处理采用 try/catch 包裹，失败时通过 wx.showToast 提示用户，成功路径则 setData 更新进度或结果。
- WXML 中使用 wx:if 条件渲染与 wx:for + wx:key 列表渲染，事件通过 bindtap/catchtap 绑定到 Page 方法，参数通过 data-id 传递。
