- 每个第三方平台在 data 中以独立对象（如 garminCn/garminCom/coros）统一维护 bound、displayName、loading 三个字段，并通过动态 key `${currentPlatform}.bound` 更新状态。
- 所有云端交互统一通过 wx.cloud.callFunction({ name: 'garminAuth', data: { action, ... } }) 发起，action 值区分不同操作（bindWithPassword、corosBind、submitMfa、unbind）。
- 异步操作采用 try/catch + setData 设置 loading 标志的模式，错误统一通过 wx.showToast 提示，成功时先更新本地状态再 setTimeout 刷新数据。
- 弹窗类交互（绑定、MFA）通过 showXxxModal 布尔变量控制显隐，输入框通过 value + bindinput 双向绑定到 data 字段。
