# 佳捷同（微信小程序 / miniprogram-1）

「佳捷同」是一款把**运动手表数据**在不同平台之间互相同步的工具。本仓库是 **微信小程序版本**，运算逻辑跑在**微信云函数**上（云端执行，不占手机资源）。

> 项目仍处于开发阶段，当前为私有仓库，尚未正式发布。

## 开发背景（为什么做这个）

1. **本人是个热衷于马拉松训练的跑者**，平时喜欢把运动数据放到各个平台去做分析。跑团里的小伙伴也恰好需要把数据同步到佳明，去参加天梯排名。之前大家一直用「佳某通」这类软件，但它更新之后开始收费，而且收费方式不合理、软件也越来越臃肿，于是就想自己搞一个。
2. **最近听说 AI 编程发展得非常快、效果也很好**。我虽然是计算机专业出身，但对编程几乎一窍不通，又是个喜欢折腾的人，就想借这个机会试试用 AI 写一个程序、看看效果到底如何。正好自己就有这个真实需求，就拿它当第一个练手项目。

> 声明：作者本人对程序开发基本一窍不通，也不懂开源社区的规矩。文档、代码里如果有任何不专业、不合规矩、或冒犯到别人的地方，**非常欢迎指正**，我会认真学习并修正。

## 它能做什么

与安卓版功能一致：把运动记录在 **Garmin 国行 / Garmin 国际服 / COROS 高驰** 之间双向同步。

| 方向 | 说明 |
|------|------|
| 国行 ↔ 国际服 | Garmin 国服与国际服互传 |
| 高驰 → 国行/国际服 | 把高驰记录同步到 Garmin |
| 国行/国际服 → 高驰 | 把 Garmin 记录同步到高驰 |

## 技术架构（大白话）

- **前端**：微信小程序原生（WXML / WXSS / JS），页面同安卓版：首页、账号绑定、同步、记录
- **后端**：**微信云开发（云函数）**，同步的核心逻辑在云端运行
- **云函数清单**：

| 云函数 | 职责 |
|--------|------|
| `garminAuth` | Garmin 登录鉴权 |
| `garminSync` | Garmin 活动上传 / 下载 |
| `corosSync`  | 高驰活动上传 / 下载 |
| `syncRecord` | 同步记录读写 |
| `quickstartFunctions` | 微信云开发初始化示例（可删） |

代码位置（给想看的人）：

```
miniprogram/        # 小程序前端
cloudfunctions/     # 云函数（后端逻辑）
```

## 本地构建与运行（给开发者）

环境要求：

- 微信开发者工具
- 一个已开通「云开发」的微信小程序账号
- Node.js（云函数依赖安装用）

步骤：

1. 用**微信开发者工具**打开本目录（根目录即小程序项目，`miniprogram/` 为前端根、`cloudfunctions/` 为云函数根）。
2. 在工具里开通**云开发**环境。
3. 右键 `cloudfunctions/` 下每个云函数 → 「上传并部署：云端安装依赖」。
4. 编译预览小程序。

> 云函数依赖安装见各函数目录内的 `package.json`；部署脚本参考根目录 `uploadCloudFunction.sh`。

## 与安卓版的区别（重要）

| 维度 | 小程序版 | 安卓版（jjt-app） |
|------|----------|-------------------|
| 运行位置 | 微信云函数（云端） | 手机本地 WebView |
| 上传机制 | 云函数用服务端 HTTP 直传文件 | 手机本地发请求，曾因桥接层转格式出 415 |
| 账号体系 | 微信登录 + 各平台 OAuth | 各平台 OAuth 本地存储 |

两者功能目标相同，实现路线不同，分属两个独立仓库维护。
