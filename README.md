# 佳捷驰（微信小程序版 / 已归档）

> ⚠️ **本分支已归档，开发中止（2026-07）**
>
> 中止原因：根据《微信小程序平台运营规范》，小程序不得收集用户在第三方平台（Garmin/COROS）的账号密码，
> 而官方建议的 OAuth 开放 API 方案无法覆盖本项目核心的「向平台写入活动」能力（Garmin/COROS 均不提供活动导入类开放接口），
> 因此无法通过平台审核公开发布。功能完整的替代品为本仓库 main 分支的 **安卓版佳捷驰**。
>
> 归档时状态：功能完整可用（三平台双向同步/去重/MFA/选项记忆/关于页），可以体验版形式自用。

「佳捷驰」是一款把**运动手表数据**在不同平台之间互相同步的工具。本分支是 **微信小程序版本**，运算逻辑跑在**微信云函数**上（云端执行，不占手机资源）。

> 项目处于归档状态，不再继续开发。

## 它能做什么

与安卓版功能一致：把运动记录在 **Garmin 国行 / Garmin 国际服 / COROS 高驰** 之间双向同步。

| 方向 | 说明 |
|------|------|
| 国行 ↔ 国际服 | Garmin 国服与国际服互传 |
| 高驰 → 国行/国际服 | 把高驰记录同步到 Garmin |
| 国行/国际服 → 高驰 | 把 Garmin 记录同步到高驰 |

## 技术架构（大白话）

- **前端**：微信小程序原生（WXML / WXSS / JS），页面同安卓版：首页、账号绑定、同步、记录
- **后端**：**微信云开发（云函数）**，同步的核心逻辑在云端运行
- **云函数清单**：

| 云函数 | 职责 |
|--------|------|
| `garminAuth` | Garmin 登录鉴权 |
| `garminSync` | Garmin 活动上传 / 下载 |
| `corosSync`  | 高驰活动上传 / 下载 |
| `syncRecord` | 同步记录读写 |
| `quickstartFunctions` | 微信云开发初始化示例（可删） |

代码位置（给想看的人）：

```
miniprogram/        # 小程序前端
cloudfunctions/     # 云函数（后端逻辑）
```

## 本地构建与运行（给开发者）

环境要求：

- 微信开发者工具
- 一个已开通「云开发」的微信小程序账号
- Node.js（云函数依赖安装用）

步骤：

1. 用**微信开发者工具**打开本目录（根目录即小程序项目，`miniprogram/` 为前端根、`cloudfunctions/` 为云函数根）。
2. 在工具里开通**云开发**环境。
3. 右键 `cloudfunctions/` 下每个云函数 → 「上传并部署：云端安装依赖」。
4. 编译预览小程序。

> 云函数依赖安装见各函数目录内的 `package.json`；部署脚本参考根目录 `uploadCloudFunction.sh`。

## 与安卓版的区别（重要）

| 维度 | 小程序版 | 安卓版（jjt-app） |
|------|----------|-------------------|
| 运行位置 | 微信云函数（云端） | 手机本地 WebView |
| 上传机制 | 云函数用服务端 HTTP 直传文件 | 手机本地发请求，曾因桥接层转格式出 415 |
| 账号体系 | 微信登录 + 各平台 OAuth | 各平台 OAuth 本地存储 |

两者功能目标相同，实现路线不同，分属两个独立仓库维护。
